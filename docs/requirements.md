**Границы проекта**

1. ## MVP \- минимальный набор

**Цель**: разработать работающий плагин для JetBrains IDE, в котором виртуальная утка отображается непосредственно в среде разработки, реагирует на действия пользователя и сохраняет своё состояние.

| Функциональность | Что конкретно должно работать |
| ----- | ----- |
| Отображение питомца | Утка отображается в отдельном окне или панели IDE. |
| Анимации | Реализовано минимум 2 состояния утки: ***idle***, ***working***. (Другие состояния ***happy***, ***sad***, ***sleeping \-*** должны легко добавляться в проект) |
| Отслеживание событий | Плагин отслеживает активность пользователя в редакторе, например количество введенных символов. |
| Реакция на события | 1\) При наступлении события утка радуется и показывает соответствующее сообщение.2\) После определенного времени бездействия утка начинает скучать, а затем засыпает.3\) При возобновлении активности утка просыпается и приветствует пользователя. |
| Взаимодействие с питомцем | Пользователь может взаимодействовать с уткой, например нажать на неё, чтобы получить случайные сообщения из заранее подготовленного набора. |
| Сохранение состояния | Состояние питомца и накопленная статистика сохраняются между перезапусками IDE. |

**Критерий готовности MVP**: пользователь устанавливает плагин, открывает JetBrains IDE, видит утку, работает с кодом и наблюдает за её реакциями. После перезапуска IDE питомец сохраняет накопленный прогресс.

2. ## MVP \- максимум

**Цель**: расширить возможности питомца, добавить игровые механики и сделать взаимодействие с ним интереснее. Реализация этих функций зависит от оставшегося времени после завершения MVP.

| Функциональность | Что конкретно должно работать |
| ----- | ----- |
| Интеграция с Git | Утка реагирует на создание коммитов, радуется успешному завершению работы. |
| Debug Duck | Возможность обсудить с уткой проблему, возникшую при разработке. Утка задаёт наводящие вопросы (здесь из локального пула вопросов, то есть они будут обобщенные). |
| Интеграция с LLM | Подключение языковой модели для генерации ***осмысленных*** ответов в режиме Debug Duck вместо заранее подготовленных вопросов и фраз. |
|  |  |
| Статистика пользователя | Отображается количество введенных символов, коммитов и время активности пользователя. |
| Достижения | Пользователь получает награды за определённые действия: первый коммит, 10 000 введённых символов, длительную работу и т. д. |
| Система опыта и уровней | Утка получает опыт за активность и постепенно развивается, открывая новые возможности. |
| Кастомизация | Возможность менять внешний вид утки и открывать новые аксессуары за достижения. |
| Настройки | Пользователь может изменять пороги AFK, отключать уведомления и настраивать реакции питомца. |
| Время суток | Утка меняет поведение в зависимости от времени дня: утром бодрая, вечером сонная, ночью удивляется активности пользователя. |
