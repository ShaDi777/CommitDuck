## **День 2\. Реализуем MVP**

Цель дня: Утка реагирует на реальные действия пользователя, с ней можно взаимодействовать, а состояние и прогресс сохраняются.

### **Участник 1 — Plugin Developer**

| Задача | Описание задачи | Definition of Done |
| ----- | ----- | ----- |
| 1\. Отслеживать активность в редакторе | Подключить `DocumentListener` для отслеживания изменений документов. При добавлении текста отправлять событие с количеством введенных символов. Сам текст не сохранять.  | При вводе текста плагин корректно определяет количество добавленных символов и передает событие в Pet Logic.  |
| 2\. Отслеживать активность пользователя  | Реализовать механизм определения активности в IDE. Для первой версии достаточно учитывать ввод текста и взаимодействие с редактором.  | При действиях пользователя фиксируется активность, а при её отсутствии запускается отсчет времени бездействия.  |
| 3\. Подключить UI к состоянию питомца | Связать обновление состояния с отображением картинки и сообщения. | При смене состояния утки меняется ее изображение, а при необходимости отображается сообщение. |
| 4\. Реализовать взаимодействие с уткой  | Добавить обработчик нажатия на изображение питомца. При нажатии запрашивать случайную фразу у Pet Logic.  | Нажатие на утку вызывает сообщение или другую видимую реакцию.  |

### **Участник 2 — Duck Logic Developer**

| Задача | Описание задачи | Definition of Done |
| ----- | ----- | ----- |
| 1\. Реализовать реакцию на активность  | При получении события активности переводить утку в `WORKING`. При достижении определённого количества символов показывать радостное сообщение.  | Ввод текста меняет состояние питомца, а достижение заданного порога вызывает сообщение.  |
| 2\. Реализовать реакцию на бездействие | Добавить отслеживание времени с последнего события активности. Например, через 10 минут утка начинает скучать, через 30 минут засыпает. Значения оформить как константы.  | При наступлении заданных интервалов меняется состояние питомца и появляется соответствующая реакция.  |
| 3\. Реализовать возвращение пользователя  | При возобновлении активности после бездействия возвращать утку в рабочее состояние и показывать приветственное сообщение.  | После периода бездействия первое новое действие пользователя пробуждает утку и вызывает приветствие.  |
| 4\. Добавить дополнительные состояния  | Добавить `HAPPY`, `SAD`, `SLEEPING` в модель и обработку переходов. Если времени мало, состояния могут отличаться только изображением и сообщением, без сложной анимации.  | Все состояния можно вызвать через события, переходы между ними работают корректно.  |

### **Участник 3 — Integration & Persistence Developer**

| Задача | Описание задачи | Definition of Done |
| ----- | ----- | ----- |
| 1\. Подключить сохранение прогресса  | Связать Pet Logic с компонентом сохранения. Сохранять количество введенных символов и необходимые данные о питомце.  | Прогресс обновляется и сохраняется в процессе работы.  |
| 2\. Реализовать восстановление состояния | При запуске плагина загружать сохраненные данные и передавать их в логику питомца.  | После перезапуска IDE количество введенных символов и накопленный прогресс не обнуляются.  |
| 3\. Интегрировать компоненты  | Объединить обработчики событий IDE, логику питомца, отображение и сохранение данных.  | Все компоненты работают вместе, основные сценарии проходят без ручного вмешательства.  |
| 4\. Провести проверку MVP  | Проверить запуск, ввод текста, достижение порога, бездействие, возвращение, клик по утке и перезапуск IDE.  | Все обязательные сценарии проверены, критические ошибки исправлены.  |

### **Definition of Done для всего MVP**

К концу второго дня должно выполняться следующее:

* Плагин устанавливается и запускается в IntelliJ IDEA.
* Утка отображается в IDE и имеет четыре состояния.
* Ввод текста учитывается как активность.
* Утка реагирует на активность и бездействие.
* После возвращения пользователя утка просыпается и приветствует его.
* По нажатию на утку появляется реакция.
* Мотивационные фразы отображаются в нужных ситуациях.
* Прогресс сохраняется после перезапуска IDE.
